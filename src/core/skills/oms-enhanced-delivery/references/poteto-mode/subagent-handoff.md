# Subagent handoff

Use a fresh session for a new task, fix round, follow-up, retry, or queue item.
The standalone brief includes the original task, every later directive, exact
base and head, prior findings and responses, unresolved objections, outputs or
branch, authority, ownership, acceptance checks, and remaining budget. A role
can outlive its agent; preserve the role in durable state, not through assumed
conversation memory. Runtime tools choose actual models and issue identities.

Reuse is allowed only when required state is costly to transfer: an isolated
checkout, uncommitted edits, a live process, or a runtime identity needed for a
bound continuation. Record the state and reason. Host restrictions still win;
if the host requires a new child for each review round, consolidate the brief
and start one. A stop or hold message is lifecycle control, not new work.

Before replacing an active writer, stop and fence it or use distinct ownership
and generation boundaries. Track both runtime handles until terminal state.
A late result from the old generation cannot write or become current evidence.
Replacement does not authorize discarding uncommitted work. If state cannot be
transferred safely, report the gap and preserve it.

Review actual outputs and bind results to the same revision and method. A
launch acknowledgment, reused name, or previous clean verdict is not proof
of the new round. Follow the host's child-task tools, workspace binding, and
model attribution requirements rather than inventing a background session.
