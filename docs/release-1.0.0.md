# OMS 1.0.0

OMS 从聚合插件重建为 Windows 开发环境启动包。安装时选择工具和目标环境，
由 OMS 完成原生插件注册及后续管理。

- 收录 pstack-claude、AIHero Skills 和独立可选的 pstack 书籍。
- Codex、Claude Code、T3 Code 为并列目标，共用宿主安装时避免重复注册。
- pstack 内置 T3 适配，保留上游工作流与模型规则，没有额外安装开关。
- 支持安装、状态、配置指引、更新、卸载；更新失败时尝试恢复旧注册。
- 书籍下载校验 SHA256，卸载保留个人文件。

## 安装

下载并解压 `oms-1.0.0-windows.zip`，在目录中运行 `./oms.ps1`。
需要 Windows PowerShell 5.1 或 PowerShell 7，以及 Git 和所选开发宿主。
登录和原生授权由用户完成。首次安装的插件需要刷新或重新启动会话。

## 旧版迁移

这是不继承旧提交的全新主分支；已有 Git checkout 建议重新克隆。
旧版 OMS 聚合插件不再由新版安装，不能直接原地更新为新版。
先用宿主原生列表确认旧 `oh-my-stack` 插件，移除明确属于旧版的安装，
再运行新版。保留个人模型配置、其他插件和书籍文件；不自动接管同名 pstack。
历史 Release 和书籍资产保留归档，不是新版安装入口。
