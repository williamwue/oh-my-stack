# 1.0.0 发布前审查

## 范围

OMS 为 Windows 安装管理脚本，工具与目标环境分开。pstack 在下载后的管理目录
应用最小 T3 映射，再由宿主原生注册。仓库没有第三方源码副本、模型路由或调度器。

## 修复与验证

- 更新缓存检查实际 Git HEAD、适配文件和非适配修改；旧包保留。
- 注册来源冲突拒绝自动接管；切换失败尝试恢复旧插件与市场。
- 多个环境关联同一物理插件，最后一个关联移除后才原生卸载。
- 混合成功/失败明确显示具体错误，禁用状态不报告为已启用。
- 书籍文件名按目录校验，不删除个人笔记；下载中断逐个保留管理记录，
  使用唯一临时文件并清理，避免重试被自身残留阻塞。
- 新版阅读入口和授权记录不依赖旧 Git 提交；历史电子书资产独立保留。
- 33 项本机回归断言通过；PowerShell 语法、UTF8 BOM、Git 空白检查通过。
- 真实 Codex 安装、67/27 个 skills 发现和四个书籍文件的 SHA256 已验证。

未发现阻止发布的本机已验证范围问题。Claude Code 原生验证因未安装跳过，
T3 新会话自动加载与派发未验收；这两项在发布说明中明确列出。

## 远端切换

以无父提交的新根提交替换 `main`，不把旧主分支历史合入新版。
推送使用精确旧远端 SHA 的 `--force-with-lease`，远端发生其他更新时停止覆盖。
旧版 Release、标签与书籍下载资产保持归档；不删除已发布资源。
因此本次不承诺清除 GitHub 上所有旧对象或历史引用，只重建新版主分支。

版本使用 `v1.0.0`。下载包从已提交的 tag 导出，附 SHA256 校验文件。
首次新版不生成旧历史的自动 changelog，使用仓库中的明确发布说明。

## 本机迁移

当前 Codex 原生列表没有启用的旧 OMS 聚合插件，pstack 和 AIHero 已由新版管理，
无需卸载其他插件。使用正常数据目录重复安装验证幂等性，安装可选书籍。
保留个人模型、其他插件和原仓库的本地备份。
