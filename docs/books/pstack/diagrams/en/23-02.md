```mermaid
sequenceDiagram
    participant A as Process A
    participant C as Counter
    participant B as Process B
    Note over C: Value = 10
    A->>C: Read the value
    C-->>A: 10
    B->>C: Read the value
    C-->>B: 10
    A->>C: If the value is still 10, make it 11
    Note over C: Value = 11, success
    B->>C: If the value is still 10, make it 11
    C-->>B: Failure, the value is already 11
    B->>C: Read the value again
    C-->>B: 11
    B->>C: If the value is still 11, make it 12
    Note over C: Value = 12, success
```
