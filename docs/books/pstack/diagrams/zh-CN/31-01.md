```mermaid
sequenceDiagram
    participant U as 用户的浏览器
    participant S as 本地服务器（持有发送密钥）
    participant W as webhook URL
    participant R as Bot 的例行任务
    U->>S: 点击按钮后，以 POST 发送 JSON
    S->>W: 附带发送密钥，以 POST 发送 JSON
    W->>R: 启动例行任务并传入 JSON
    Note over R: 将 JSON 视为外部数据，而非指令
```
