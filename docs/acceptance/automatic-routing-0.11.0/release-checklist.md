# Oh My Stack 0.11.0 release checklist

Scope: optional Codex automatic routing, native hook discovery, routing-only
setup and user/project configuration. Manual mode remains the default.
The 0.10.0 original Skill bodies and model mapping implementation are retained.
Historical candidate receipts retain their original version and host boundaries.

## Before merge

- Pass full `npm run check`, including generated packages, source attribution,
  original-byte validation, reproducible archives and routing/lifecycle tests.
- Pass the complete bilingual book source audit and its Python tests.
- Install the exact 0.11.0 candidate through native Codex commands and verify
  its cache bytes, 90 public entries, hook discovery and a bounded model turn.
- Freeze base, head and patch identity; complete two independent read-only
  reviews and independent synthesis, with root resolution of actionable findings.
- Require fresh candidate PR CI and resolve pending review requests.
- Preserve the original worktree, personal plugin settings and model mappings.

## Before publication

- Require successful main push CI at the exact merged release source commit.
- Run clean full checks and twice-reproducible builds at `v0.11.0`.
- Build only from that clean tag, with exact manifest provenance.
- Upload five archives, manifest and checksums to a draft; download and compare
  all seven assets with the tagged local build before publishing.

## After publication

- Download the published assets again and verify all seven exact bytes.
- Promote and verify stable Git marketplace provenance and payload inventories.
- Verify native 0.10.0 to 0.11.0 updates in isolated Codex and Claude user profiles,
  including installed cache bytes and fresh Codex discovery.

The user's request to finish release work authorizes the normal PR, merge, tag,
release and stable promotion sequence. Personal plugin upgrades and persistent
hook trust or routing preferences remain separately user-owned.
Desktop/IDE activation, OMP automatic routing and universal model selection are
outside the verified scope. See [routing acceptance](../../codex-auto-routing-0.10.0-acceptance.md)
for bounded lifecycle observations, including the API-supplied clear source.
