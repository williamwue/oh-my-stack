# Oh My Stack 0.11.1 release checklist

Scope: choice-based optional Codex routing setup. Installation remains manual
by default. Model setup, native hook trust and unrelated workspaces are preserved.

## Before merge

- Pass full `npm run check` and the complete bilingual book source audit.
- Preserve the dated choice observations: a default-mode text fallback, a
  structured native question with no unanswered-choice write, and a selected
  personal default that preserves a project's manual override. The native
  question feature was enabled only in disposable test processes.
- Install the exact candidate through isolated native Codex commands; verify
  its cache bytes, 90 public entries, hook discovery and a bounded setup turn.
- Freeze base, head and patch identity; complete two independent read-only
  reviews and independent synthesis, resolving actionable findings at the root.
- Require fresh PR CI and resolve pending review requests.
- Preserve the original worktree and personal plugin/model/routing settings.

## Before publication

- Require successful main-push CI at the exact merged release source commit.
- Run clean full checks and twice-reproducible builds at `v0.11.1`.
- Upload five archives, manifest and checksums to a draft; download and compare
  all seven assets with the tagged local build before publishing.

## After publication

- Download and verify all seven published asset bytes again.
- Promote stable through the existing gated publisher; verify release
  provenance and exact Codex/Claude payload inventories.
- Verify native 0.11.0 to 0.11.1 updates in isolated Codex and Claude user
  profiles, with installed cache bytes and fresh Codex discovery.

The user's request to complete submission and release authorizes the normal
PR, merge, tag, release and stable-promotion sequence. It does not change the
maintainer's personal installation or persistent hook trust. Desktop/IDE
rendering, automatic routing selection and model setup are separate evidence.
