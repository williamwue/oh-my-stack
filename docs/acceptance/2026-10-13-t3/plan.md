# T3 orchestration implementation

The implementation keeps Codex and Claude Code as installation hosts. T3 owns orchestration when the generated package explicitly selects it. The default four host packages retain their existing behavior.

## Completion predicate

- Both T3 host variants generate and validate without changing pinned workflow bodies.
- A live T3 catalog validates provider instances, model identifiers, typed options, and runnable targets.
- T3 configuration has independent scope, preserves ordered panels, and never overwrites native host model configuration.
- Prepared child tasks carry complete role and task instructions, stable retry identity, and an explicit selected target.
- Tests cover result state, cancellation, fresh review rounds, configuration isolation, PR association and event watches, and scheduling request shapes.
- The repository check passes. Live evidence is reported separately from fixtures, generated packages, installation, and unavailable cross-family execution.

## Work sequence

1. Ground generator and model resolution boundaries through independent read-only exploration.
2. Compare two caller-first architecture sketches and choose a synthesis.
3. Build typed catalog, configuration, delegation, and lifecycle checks.
4. Generate opt-in T3 bindings using the existing host package formats.
5. Add PR, schedule, browser, and device instructions that follow current host contracts.
6. Run focused checks, independent review, the complete repository check, and bounded live delegation probes.

## Scope and authority

This is a local implementation and verification run. It does not change personal provider configuration, install plugins, publish, merge, deploy, create persistent schedules, or send messages externally. Source-host workflow changes remain pinned and generated. T3 bindings add no review stages or default cross-family requirement.

## Throughput checkpoint

The main units are model and delegation support, generator and packaging support, and verification and documentation. Independent work is limited to those seams. Generated output is owned by the coordinator. Repository checks run after source integration. Available live providers are read before any live probe.
