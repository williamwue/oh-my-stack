# Oh My Stack 0.10.0 release checklist

Base: 0.9.1 plus the main-branch README cover.
Scope: five original AIHero imports, bilingual installation/update prompts,
stable marketplace distribution and post-publication promotion automation.
Existing original workflow bodies and shipped model-routing scripts are retained.

## Before landing the PR

- Pass `npm run check`, including original-byte/invocation/dependency validation,
  deterministic archive checks, documentation drift, and all 256 tests.
- Complete the CI bilingual book source audit and five Python audit tests.
- Recheck the ten bounded AIHero host fixture receipts and preservation snapshots.
- Verify native candidate installation, 89 public entries, and installed cache bytes.
- Independently review the exact frozen candidate base/head/patch and resolve blockers.
- Require fresh candidate PR CI, with no unresolved review requests.
- Preserve the dirty primary worktree and personal plugin/model configuration.

An independent verdict at this stage covers the frozen implementation and
readiness to merge. It does not certify that publication or update acceptance
has happened. The later gates remain mandatory and are completed in order.

## Before publishing the release

- Require successful merged main CI at the exact release source commit.
- Run clean full checks and twice-reproducible builds at the exact `v0.10.0` tag.
- Upload all five archives, manifest and checksums to the draft release and
  verify all seven assets before publishing it.

## After publishing the release

- Freshly download the published release and compare all seven assets with
  the trusted tagged build.
- Exercise the native promotion workflow and verify the public stable ref/provenance.
- Verify 0.9.1 to 0.10.0 updates in isolated Codex and Claude user profiles,
  including actual cache inventories and fresh Codex discovery.

Only completion of all three stages establishes that shipping is finished.

## Earlier evidence and remaining boundaries

The [AIHero candidate record](../../aihero-original-0.10.0-acceptance.md) describes
five fresh bounded projects per host, explicit confirmation gates, background
research events, exact original resources, and the limits on child attribution.
The [stable bootstrap record](../2026-10-07/stable-marketplace.md) describes only
0.9.0 to 0.9.1 observations. Neither is relabeled as a later installed version.

Desktop/IDE interactions, live OMP original workflows, automatic-update UI,
project/local/managed Claude scopes, and real remote tracker writes remain
outside this release's verified CLI scope. Fresh Skill discovery and cache
version checks do not by themselves establish a model turn executing a Skill.

The [GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.10.0)
records actual publication. Current and post-publication receipts are retained
separately from historical evidence; no passing local check alone claims release.
