# Lead judgment

Synthesis is adjudication, not vote counting. Merge equivalent findings while
preserving attribution. Consensus increases signal, but the final category
depends on traced evidence and the actual intent.

Dismiss unreachable hypotheticals, preferences presented as defects,
recommendations that contradict known constraints, and abstraction added for no
current second use. Scrutinize concrete correctness and security paths even
when only one reviewer raised them. Keep `Act on` small enough to guide a real
decision, and explain dismissals so the user can override the judgment.
