# Oh My Stack 0.12.0 candidate checklist

Scope: optional Claude Code routing with independent runtime switches. No model
configuration, native hook trust, or unrelated workspaces are changed by the
package. The acceptance record preserves pre-publication facts separately from
later publication and installation receipts.

## Candidate gates

- Regenerate all packages from canonical version 0.12.0 and preserve existing
  Codex behavior and OMP unsupported routing.
- Pass full repository checks, complete bilingual book source audit/tests,
  and twice-reproducible archive builds using the pinned release environment.
- Preserve executable routing tests and native Claude observations in
  [the acceptance record](claude-auto-routing.md); exercise the final generated
  candidate in a fresh native Claude session before publication.
- Freeze the exact base, head and tree; complete independent read-only reviews
  and independent synthesis. Resolve actionable findings before tagging.
- Preserve unrelated main-worktree edits and existing personal model settings.

## Publication gates

- Tag the clean reviewed source with the canonical version. Use the local
  maintainer release command with completed tree-bound review evidence.
- Download and verify all seven draft assets before publishing, repeat public
  downloads afterward, and promote stable through the gated publisher.
- Update the existing Claude Git marketplace through its native manager; verify
  the installed version and payload bytes against the trusted release manifest.
- Verify effective routing and a fresh session separately from installation.
  Do not alter native hook trust automatically.

Actions is optional manual inspection under the current local release policy.
Local checks, independent review, publication, native installation, and observed
routing are separate evidence claims.
