# Oh My Stack 0.11.2 release checklist

Scope: current Sol recommendations and Claude 5.5 effort recognition. Explicit
model overrides, reasoning budgets, ordered panels, routing and hook trust are
preserved. User installation and requested model migrations have separate receipts.

## Before merge

- Pass full `npm run check` and the complete bilingual book source audit.
- Verify current native Codex inventory and the authenticated Claude Sonnet/Opus
  canonical IDs through bounded observations. Do not probe optional Haiku or Fable.
- Build the candidate and install it through native Codex and Claude commands
  in isolated homes. Verify exact cache inventories and fresh Codex discovery.
- Exercise the installed candidate configuration scripts with current observations
  in detached directories, checking reasoning support, complete panel order,
  legacy-pin preservation and unavailable-model rejection.
- Freeze base, head and patch; complete the configured independent reviewer
  panel and separate synthesis. Root resolves actionable findings.
- Require fresh PR CI and successful main-push CI at the merged source commit.
- Preserve the original worktree and unrelated personal configuration.

## Before publication

- Create `v0.11.2` only after the candidate gates pass.
- Run clean full checks and twice-reproducible tagged builds.
- Upload five archives, manifest and checksums to a draft. Download and compare
  all seven assets to the trusted tagged build before publishing.

## After publication

- Download and verify all seven public assets again.
- Promote stable through the existing gated publisher and verify provenance.
- Verify native 0.11.1 to 0.11.2 updates in isolated Codex and Claude homes.
- Upgrade the maintainer's Codex and Claude plugins through their existing
  native sources, verify exact cache bytes, and preserve model/routing settings.
- Apply the requested Claude Sonnet 5.5 migration using observed IDs and a
  reviewed preview. Preserve Opus, budget, routes, panel order and scope.
- Audit the installed mappings and report model execution as unverified unless
  a separate bounded child observation establishes it.

The request to finish remaining work authorizes commit, PR, merge, tag, release,
stable publication, personal plugin upgrades and the requested model migrations.
It does not authorize enabling routing, changing hook trust, adding Haiku/Fable,
or replacing unrelated user configuration. Native manager and file checks do
not certify Desktop/IDE rendering or all workflows.
