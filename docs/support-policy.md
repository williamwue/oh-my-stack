# Support policy

OMS 0.21.0 distributes Codex and Claude Code native plugin bundles and the native
Pi package. OMP, oms-auto, enhanced-delivery and the old OMS role/model engines
are retired from formal distribution. The current source receipt and package
GENERATION.json identify the fixed upstream implementation and extensions.

Static checks cover complete sources, selected AIHero originals and resources,
namespaces, unchanged default model data, generation consistency, archives,
installation, publication safety and archive-to-stable promotion. Upstream
fixtures test tool behavior without proving live model choices. T3 read-only
dispatch/terminal-return smoke is separate from model diversity or cancellation
acceptance. Windows and cross-provider model calls remain unverified here.

Existing upstream personal configuration follows normal upstream rules.
Installation does not modify it. Try defaults with isolated runtime configuration.
See the [current guide](../README.md) and [source decisions](maintainers/upstream-0.21.0.md).
