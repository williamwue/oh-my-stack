# OMS 上游对齐与真实项目验收

发布后补记：本轮改动已随 [0.2.1](releases/0.2.1.md) 发布。以下保留发布前的验收范围和历史记录；正式发布另增加一项安装包权限位回归测试，最终为 131 项测试通过。

本轮完成冻结版本的 33 项上游差异核对，并在 OMS 和 fishspeech 本地页面执行了下表中的正向与反例验收。结果不等于 pstack 全部功能、全部运行环境或全部失败路径都已验证。

OMS 基线为 `df3597a0a0622c5e62e741d02f8209393189d684`。上游比较区间为 `70b2dc8b4b85c8d5648624ca40d692c421fff32f` 至 `ecc249f1e306fc64ddf83c7bed16cacf7c2239db`，后者对应 pstack 0.15.5。工作位于独立分支 `codex/upstream-acceptance-20260928`。

## 检查与修复

完整 `npm run check` 通过，130 项测试通过，0 失败、0 跳过。它同时检查三个生成包、12 条 conformance 记录、7 个可重复构建产物，以及 7 个运行环境配置。Windows 原始 Markdown 命令因单引号曾扫描 0 个文件，修正为跨平台引号后重新执行，实际扫描 508 个 Markdown 文件，无错误。新增验收文档在最终文档检查中另行覆盖。

首次完整测试为 124/130，失败记录保留。修复包括 Git Bash 和 npm 的 Windows 调用、临时用户目录隔离，以及 Claude effort hook 对符号链接输出的拒绝。路径验证仍是词法边界；hook 的检查也不是 Windows 原子路径操作保证。

fishspeech 页面使用独立工作树与本地开发配置，没有加载生产密钥。匿名标题渲染和移动菜单已观察；认证会话 API 因缺少 `BETTER_AUTH_SECRET` 返回 500，认证和后端不在本次视觉验收结论内。组件试验补丁已保存，页面已恢复到原提交字节。

最初 JPEG 截图存在尺寸波动，已放弃该轮结果。第二轮在改动前冻结 PNG 基线、视口、标题矩形和零容差。连接中断后曾得到不带滚动条的移动截图，该截图也被放弃，并按原滚动条宽度重新测量。恢复后的移动组件仍与冻结基线逐像素相同。
