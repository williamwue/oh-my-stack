# Oh My Stack 0.19.0

The sole pstack semantic source advances from official 0.15.23 to 0.15.25 at
`99743e9c151c8537cbbf1f98bb38f34ef3368453`. The default distribution contains
78 public Skills, including explicit `sharpen`. Historical source snapshots and
exact host adaptations remain preserved. pstack-claude supplies reference ideas;
it is not an additional semantic upstream.

OMS adds a read-only official update planner that checks strict derivation
anchors, source receipts, metadata changes and local-output conflicts. Its
preview does not fetch, apply changes or advance the official source pin.

The worktree audit freezes local identities and status, then assesses fresh
supported host and merge evidence against a repeated local observation.
Incomplete evidence remains unresolved; a candidate is advisory and grants no
deletion permission. Native GitHub PR observation gains complete bounded
pagination and one shared observation budget. Partial, drifting or over-budget
reads cannot establish readiness. Existing authorization and merge journals
retain their ownership.

Native Pi delegation rejects malformed RPC envelopes and bounds inherited-pipe
draining after the direct child exits. Cancellation and observed model identity
retain their separate evidence requirements. Documentation checks now compare
current version, upstream and default-catalog facts with authoritative files.
The OMP native installation gate loads the bundled `poteto-help` entry, matching
the default catalog.

The explicit AIHero extension adds `triage`, `wayfinder`, `wizard` and
`git-guardrails-claude-code` from upstream `49dd158`. Default release archives
retain native bindings; T3 remains an explicit source build. Installation must
preserve selected extensions, host bindings and personal model/routing settings.

Formal source validation, published archives, stable promotion and native
installation have separate receipts. Static consistency does not establish
backend enforcement of model options or universal live workflow equivalence.
