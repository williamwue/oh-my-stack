# Oh My Stack 0.8.0

This version adds Matt Pocock's original `codebase-design` to the 0.7.0
pstack-derived core. The catalog has 79 public entries: 55 workflows and
24 principles, plus 12 internal probes. All three target packages share it.

## Original capability

The complete upstream skill, `DEEPENING.md`, `DESIGN-IT-TWICE.md`, and
`agents/openai.yaml` are pinned at
`mattpocock/skills@6fd947921b935b7e1e69293a200400f0fdd5c15f` and copied
byte for byte. The upstream MIT license and source coordinates accompany the
selected skill. Its original invocation and design instructions are preserved;
no OMS workflow or delegation binding is injected.

The source manifest records every resource hash. Generation rejects changed
originals, omitted declared skill dependencies, unrecorded resources, unsafe
paths, snapshot symlinks and skill-name conflicts. Package validation checks
the original file hashes again. Existing pstack capabilities remain separate.

## Acceptance and publication

See the [usage guide](../aihero-original-skills.md),
[first bounded design acceptance](../aihero-original-acceptance-2026-10-06.md),
and [0.8.0 candidate checklist](../acceptance/aihero-0.8.0/README.md).
The original design scenario completed on Codex project-local discovery and
Claude Code session-plugin invocation, each with three independent designs
and a parent comparison. Those dated runs were collected on the 0.6.0 source
baseline; their skill bytes are the same pinned originals in this release.
They do not establish automatic trigger quality, full workflow parity, or OMP
live behavior. Native plugin discovery and personal installation are recorded
separately when executed.

Publication status is recorded in the
[GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.8.0).
Release gates retain exact-candidate review, fresh remote CI, clean tagged
checks, deterministic builds, and comparison of every downloaded asset.
Native managers determine the installed version. The next source candidates
remain original `domain-modeling`, then the complete dependencies for
`grill-with-docs` and `improve-codebase-architecture`; none are partially
included in 0.8.0.
