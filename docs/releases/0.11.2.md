# Oh My Stack 0.11.2

Model setup now recommends GPT-6.1 Sol for routine implementation and the Sol
position in ordered panels. This updates the Codex `pstack` preset and OMP's
`pstack-openai-codex` alternative. GPT-6 Astra and Luna, preset reasoning
efforts, and panel counts retain their existing roles.

Claude Code setup continues to observe the canonical models behind `sonnet`
and `opus`, with Haiku optional. The collector now recognizes Sonnet 5.5 and
Haiku 5.5 effort levels; Opus 5.5 was already recognized. Unknown Haiku versions
stop collection rather than inheriting Haiku 4.5's lack of an effort override.
The current Claude Code version requirements are documented in the
[model guide](../model-configuration.md).

Plugin upgrades preserve user model mappings. Re-run model setup to preview
new preset defaults; explicit model pins remain preserved. A missing recommended
model requires an explicit observed choice and never causes a silent downgrade.
Setup still keeps file configuration separate from runtime model execution.

The release retains 90 public Skills and the existing original Skill bytes.
See the [candidate observations](../acceptance/2026-10-08/model-recommendations.md)
and [release checklist](../acceptance/model-recommendations-0.11.2/release-checklist.md).

Publication is recorded at the
[GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.11.2).
