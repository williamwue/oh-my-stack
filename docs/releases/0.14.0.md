# Oh My Stack 0.14.0

This release restores the pstack delivery contract in the portable OMS
workflows. `poteto-mode` supplies the shared contract, and `feature`,
`figure-it-out`, `how`, and `visual-parity` retain their specific execution
and verification requirements in Codex, OMP, and Claude Code.

Delivery acceptance now has executable checks for frozen evidence, independent
review, protected sources, PNG comparison, and native worker attribution.
Missing review evidence rejects acceptance even when a behavior probe passes.
See [delivery evidence](../delivery-evidence.md) for the supported receipt
format, checks, and limitations.

Automatic engineering routing loads the shared poteto contract after its
configuration gate. SessionStart remains a routing hint rather than a
host-enforced dispatcher; this release does not guarantee every eligible
request selects OMS. Explicit Skills and routing exclusions still take precedence.

The implementation completed four independent review rounds and a clean
pinned maintainer pipeline. Historical failed probes and repairs remain
available under [the fidelity evidence](../acceptance/2026-10-09/pstack-fidelity/synthesis.md).
These bounded results do not establish universal upstream equivalence or
complete native attribution for encrypted historical assignments.

Update the native plugin installation and start a fresh session to load the
new Skill set. Model mappings and automatic routing settings remain separate.
