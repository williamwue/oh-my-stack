# Oh My Stack 0.7.0 candidate

This source candidate reviews pstack 0.15.5 through 0.15.13 and adds four public
Skills: correct, benchmark-checklist, principle-explain-the-number, and
poteto-help. The catalog has 78 public entries: 54 workflows and 24 principles,
plus 12 internal probes. Codex, OMP, and Claude Code packages share that catalog.

## Behavior

- Help reads the generated catalog and answers without starting the requested
  workflow. Explicit work requests route through poteto-mode.
- Correct requires repeated attributable mistakes, structural enforcement, and
  proof that the constraint rejects an authentic past failure.
- Performance comparisons check failures, completed work, tuning, sampling,
  spread, limiting resources, and end-to-end relevance before selecting a win.
- Architecture checks include ownership, duplicate paths, exposed internals,
  and duplicated lists. Type-first validators must prove the complete type.
- Fresh child sessions receive consolidated scope; host-owned child lifecycle
  rules take precedence. Active writers are fenced before replacement.
- Standing programs default to hourly audits through verified host scheduling,
  with bounded wakes and durable pause when unsupported.
- PR preparation follows host-owned tooling, task association requirements,
  repository templates, and actual publication authority.

## Source and acceptance

All 33 changed upstream paths have decisions. Immutable old and new snapshots
retain their Git blob identities and SHA-256 hashes. Current derived outputs
have one source owner; the dated transition receipt retains prior ownership.
Older source pins, book editions, and acceptance evidence remain historical.

See the [update guide](../upstream-pstack-0.15.13.md) and
