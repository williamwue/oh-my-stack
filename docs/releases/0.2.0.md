# Oh My Stack 0.2.0

First non-beta release, prepared on 2026-09-26.
Release tag: `v0.2.0`.
The [candidate record](0.2.0-candidate.md) tracks completed checks, excluded
attempts and the explicit Claude validation waiver. Publication is confirmed
by the [GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0),
not merely by the presence of this document.

## Verification and waiver

The candidate passed 121 repository tests, reproducible builds, three-host
package upgrade/rollback checks, and bounded Codex/OMP runtime acceptance.
Native Codex and Claude upgrades preserved existing role files.

**Fresh Claude Code authenticated validation was skipped with the user's
explicit approval on 2026-09-26 after an account-limit failure.** Its model
probe and candidate worker run are not verified. Prior beta.5 Claude results
are historical evidence, not a fresh 0.2.0 runtime pass. Package lifecycle
checks passed independently. Workflow instructions and helpers are unchanged
from beta.5; full parity and external integrations remain outside this release.

## Scope

74 directly selectable Skills (51 workflows and 23 principles) for Codex, OMP
and Claude Code, with explicit setup, runtime-specific model routing and safe
package lifecycle tools. Workflow behavior is unchanged from beta.5.
See the [support policy](../support-policy.md): advanced external integration,
live-worker reattachment and full Cursor parity are not release guarantees.

## Added acceptance

Claude Code continuation passed controlled natural late-payload rejection,
actual-crash checkpoint pickup, stale-HEAD rejection and two architect rounds.
These are bounded local observations, not cross-host or production guarantees.
See the [record](../claude-continuation-acceptance-2026-09-26.md).

## Upgrade

Retain beta.5 archives and manifest for rollback. Upgrade the plugin through
its native manager or the owned-directory installer, then start a fresh host
session and verify its version and source. Existing setup is separate and
must be preserved. Do not run setup apply merely to upgrade package files.
Project overrides continue to take precedence over user defaults.
