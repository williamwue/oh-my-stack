# Oh My Stack 0.11.0

This release adds optional automatic engineering routing in Codex. After opting
in and reviewing the native hook, describe an engineering task without selecting
`poteto-mode` each time. OMS uses the existing workflow appropriate to that task.

Manual mode is the default. User/project switches are independent of model
configuration, and the nearest project switch overrides the user setting.
Explicit Skills, requests to skip OMS, ordinary chat and translation retain
priority. Narrow tasks use the smallest appropriate existing workflow; broader
investigation and independent review depend on evidence or an explicit request.

Use [automatic routing](../automatic-routing.md) or its
[Chinese guide](../zh-CN/automatic-routing.md) to enable or disable it.
Routing-only setup previews the switch and does not run model inventory or probes.

The Codex package now declares `./hooks/hooks.json` in its native manifest and
omits root `plugin.json`, which shadowed hook discovery in the tested 0.160.1
loader. Package and release checks reject that shadowing file. Upgrades replace
owned package files while preserving user/project routing preferences.

The package has 90 public Skills, including the new `oms-auto` entry. Original
AIHero bodies and resources retain their pinned bytes and invocation policies.
Claude Code and OMP retain explicit engineering entry points; this release does
not claim automatic routing on those hosts.

The [release checklist](../acceptance/automatic-routing-0.11.0/release-checklist.md)
separates candidate review, publication, stable promotion and installed updates.
[Historical candidate acceptance](../codex-auto-routing-0.10.0-acceptance.md)
records installed CLI startup/resume/compact, API clear-source, manual,
translation and explicit-entry observations. A routing hint does not guarantee
model selection, and Desktop/IDE behavior remains unverified.

Published assets and publication status are available from the
[GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.11.0).
Start a fresh session after a native plugin update. Enable automatic routing and
review the current hook explicitly; installing a package does not trust its hook.
