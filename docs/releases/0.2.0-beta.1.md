# Oh My Stack 0.2.0-beta.1

This first beta retains 74 directly selectable public Skills across the
generated targets. It improves OMP installation safety without claiming that
OMP's `plugin link --dry-run` is fixed or that every Cursor pstack workflow has
been executed on every host.

## Changes since alpha.11

- Added `tools/check-omp-install.mjs`: it checks the OMP archive checksum and
  exact installed-tree inventory, then performs a real install in a randomly
  named isolated OMP profile. It checks the listed version and resolved package
  path, plugin health, Skill loading, and probe cleanup. User-profile install
  is a separate, explicit step.
- Replaced the unsafe OMP dry-run release gate with this reproducible
  preflight and isolated-install procedure. OMP 18.3.0 still writes a link and
  lock entry when `plugin link --dry-run` is used; do not use that command as a
  read-only preview.
- Kept Codex and OMP user-level setup choices and generated workflow content
  unchanged from alpha.11.

## Local acceptance on 2026-09-24

- From a clean beta.1 checkout, `npm ci --ignore-scripts`, `npm run check`
  (108 tests), reproducible release build, and all five SHA-256 checks passed.
- OMP 18.3.0 passed the beta.1 isolated-profile gate. The normal profile then
  installed beta.1, reported healthy through `plugin doctor`, and completed a
  read-only `prove-it-works` turn that loaded the installed Skill and read
  `.git/HEAD`. The existing OMP setup manifest did not change.
- Codex CLI 0.155.1 installed beta.1 from the local marketplace bundle. A new
  app-server process discovered all 74 enabled public Skills at beta.1 cache
  paths. A fresh read-only turn selected `prove-it-works` through a structured
  Skill input; the persisted turn included the full installed Skill body and
  verified the workspace and Git status. The existing Codex setup manifest
  did not change.
- The beta.1 setup-acceptance scripts rechecked the earlier real
  `how.explorer` parent/child records: OMP native role and Codex explicit
  spawn both matched Luna at high reasoning. This is **regression verification
  of prior records**, not fresh worker execution after this upgrade.

An unrelated optional OMP Vercel MCP connection returned HTTP 401 during the
read-only turn; that integration was not used by Oh My Stack acceptance.

## Boundaries

Claude Code remains packaged and validated offline, without authenticated
runtime acceptance. Codex Desktop picker coverage, every named route and
multi-worker panel, real external-system workflows, provider diversity, and
full Cursor pstack parity remain unverified. See the [release process](../release-process.md)
for installation checks and the [candidate record](0.2.0-beta.1-candidate.md)
for prepublication evidence.
