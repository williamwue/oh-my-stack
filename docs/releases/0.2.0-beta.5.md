# Oh My Stack 0.2.0-beta.5

Prerelease focused on review evidence and bounded Claude Code collaboration.

Published as [v0.2.0-beta.5](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-beta.5).

## Changes

- Interrogate requires root-observed runtime metadata for model claims.
- Arena requires complete frozen candidate artifacts for cross-judgment.
- Claude setup acceptance handles one selected cross-judge without weakening
  ordered runner-panel checks.
- Installation checks independently read quoted source and exclude child
  role-policy markers from file contents.
