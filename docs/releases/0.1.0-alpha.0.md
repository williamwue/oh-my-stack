# Oh My Stack 0.1.0-alpha.0

This is the first local Alpha release candidate. It produces OMP, Codex, and
Claude Code packages from the same portable source version. No public tag or
hosted release is implied by this document.

## Package verification

| Target or surface | Static | Discovery | Package lifecycle | End-to-end workflows |
| --- | --- | --- | --- | --- |
| OMP 18.2.6 CLI | Verified | Verified for the public Skill matrix and explicit loading | Generic archive and npm artifact lifecycle verified; native plugin-manager D1 remains unresolved | Six same-scenario conformance fixtures verified; broader W3 remains incomplete |
| Codex CLI 0.155.1 | Verified | Verified for the public Skill matrix and explicit loading | Generic archive and repository-marketplace lifecycle verified | Six same-scenario conformance fixtures verified |
| Codex desktop | Verified package only | Not tested | Generic archive lifecycle verified | Not tested |
| Codex IDE | Verified package only | Not tested | Generic archive lifecycle verified | Not tested |
| Claude Code | Verified package only | Deferred until an authenticated local runtime is available | Generic archive lifecycle verified | Deferred until an authenticated local runtime is available |

The six paired workflow scenarios are bug fix, feature boundary,
behavior-preserving refactor, architecture candidates, mixed review, and
conflicting writers. Each OMP and Codex record passes the same semantic
assertions; adapter events and isolation strategies may differ.

## Release artifacts

`npm run release:build` creates:

- `oh-my-stack-omp-0.1.0-alpha.0.tar.gz`;
- `oh-my-stack-codex-0.1.0-alpha.0.tar.gz`;
- `oh-my-stack-claude-code-0.1.0-alpha.0.tar.gz`;
- `release-manifest.json` with exact file inventories and maturity labels;
- `SHA256SUMS` for all archives and the manifest.

The archives contain no runtime credentials, live transcripts, conformance
evidence, repository tools, or user configuration.

## Security and trust

The default packages contain Skills, generated role definitions, model setup
scripts, and one Skill-local shell helper. Skills remain untrusted instructions
until reviewed. Scripts are executable code and are never run by the release
installer. The inventory collector may use an authenticated runtime's network
path only when the user explicitly executes it. The configuration script is
offline and writes only to a user-selected directory.

No Hook, MCP server, recurring automation, external mutation, pull request, or
merge is enabled by installation. Future packages that add one of those
surfaces must declare it separately.

## Known limits

- Claude Code discovery and workflow behavior are not live-verified.
- OMP native plugin-manager D1 is unresolved because its observed dry-run path
  mutated state; artifact lifecycle success is not substituted for that gate.
- Codex desktop and IDE have no live evidence in this release.
- The opening-a-PR workflow has a verified non-publishing fallback, not a live
  forge publication claim.
