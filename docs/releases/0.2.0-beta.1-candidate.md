# Oh My Stack 0.2.0-beta.1 candidate

This is a local release candidate, **not** a published GitHub release or a
claim of complete Cursor pstack parity. The latest public version remains
`0.2.0-alpha.11` until the beta candidate is reviewed and deliberately
published.

## Change from alpha.11

OMP release acceptance no longer depends on `plugin link --dry-run`. The new
`tools/check-omp-install.mjs` checks the OMP archive checksum and exact
installed-tree inventory, then performs a real link/install in a randomly
named isolated OMP profile. It verifies the listed version, resolved package
path, plugin health, and read-only `prove-it-works` Skill loading, then
uninstalls the probe. The normal user profile is not targeted. A fresh
link-only profile's `package_manifest: warning (Not created yet)` is accepted
only when the Oh My Stack plugin health check succeeds; all other warnings
fail. The upstream OMP dry-run defect remains unfixed.

The actual user-profile install is a separate, explicit mutation after the
gate passes. Model setup is also separate and is not performed by this gate.

## Candidate verification

On 2026-09-24, the working-tree `beta.1` build passed `npm run check` (108
tests), byte-reproducible archive checks, and all five checksums. The owned
directory installer verified the beta.1 OMP archive. OMP 18.3.0 then passed
the isolated-profile gate with the beta.1 package: absent-before Skill,
native installation, exact package target, healthy plugin, Skill load, and
probe uninstall. The default OMP plugin lock and package manifest SHA-256
values were identical before and after the probe; its installed Oh My Stack
version remained alpha.11. The probe did not run model setup.

These are working-tree results, not clean-tagged release evidence. The final
beta gate still requires a clean-checkout build and a separate publication
decision. No beta tag, remote push, or GitHub release has been made.

## Remaining boundaries

This gate proves one OMP native plugin lifecycle and Skill read, not every
workflow or route. Codex native custom-role selection, all multi-worker
panels, authenticated Claude Code, real external-system workflows, and
provider diversity remain outside this beta candidate's verification. A
beta label must not imply those are complete.
