# Oh My Stack 0.18.0

This release updates the pinned pstack core from 0.15.17 to 0.15.23 at
`ce649c03ac3b75b6ae80cbd15b7e2c536caedb5a`, preserves the complete upstream
snapshot and historical receipts, and adds the explicit-only
`in-your-own-words` Skill. The default catalog contains 77 public entries;
optional extensions retain their separate selection boundary.

The workflow bodies preserve the latest upstream coordination, verification,
review, ownership, and shipping rules through exact source derivations. The
portable plan checker now uses installed context-relative paths and correctly
parses CommonMark fences.

Native Codex and selected T3 builds support audited task effort and speed
selection without changing saved model identities. Fresh comparison panels use
the upstream default seat count while saved panels retain their membership,
order, aliases, options, and explicit constraints. Reported rejection retries
the original role line before the applicable default or equivalent fallback.

T3 refusal history binds captured requests to their original channel, validates
equivalent provenance, excludes all previously refused targets, and uses the
latest validated error's candidate IDs. A flat hash-keyed receipt ledger keeps
long legitimate rejection chains compact while rejecting forged or cyclic
records. Native inventory audit records distinguish original and refreshed
catalogs.

Default release archives and the stable marketplace retain native bindings.
T3 is an explicit source build using `--orchestration t3 --output-root`; it does
not enable a provider or rewrite personal model and routing configuration.
Configured unavailable review seats still require the workflow's prescribed
handling. This release does not silently substitute them.

The preceding local candidate passed 662 repository tests and independent
Codex code and decision-trail reviews, and its installed Codex/T3 and native
Claude payloads matched their file inventories. The user explicitly accepted
Codex-only final review because Cursor was disabled and unavailable. These
results are recorded in the
[alignment acceptance](../acceptance/2026-10-14-pstack-sync/result.md).
Formal source-bound validation, publication, downloaded assets, and final
installed version checks have separate maintainer receipts. Backend enforcement
of requested effort/speed, exhaustive UI discovery, and universal end-to-end
workflow equivalence remain unverified.
