# Oh My Stack 0.12.0

Claude Code now supports optional automatic engineering routing through its
native SessionStart hook. Ordinary engineering requests can select an OMS
workflow without an explicit `poteto-mode` invocation after opting in.

- Claude and Codex have separate user and project switches. Claude starts in
  manual mode and uses `routing.claude-code.json` for project overrides.
- `setup-oh-my-stack` can change routing independently of model setup, with
  a preview before applying the chosen scope and mode.
- Explicit Skills, Skip OMS, bounded child assignments, chat, translation,
  and tool help retain priority. Invalid switches and hook input fail closed.
- Codex keeps its existing configuration paths and default behavior.

The [Claude acceptance record](../acceptance/2026-10-08/claude-auto-routing.md)
records native startup/resume, ordinary investigation, explicit skip, manual
mode, and routing-only setup observations. Clear/compact and the native choice
and hook-review UIs have narrower verification boundaries stated there.

Update with the native Claude plugin manager and start a fresh session. Opt in
through `/oh-my-stack:setup-oh-my-stack` by selecting automatic routing and the
intended scope. Hook trust remains a native Claude control.
