# Oh My Stack 0.11.3

Claude Code model setup now includes Haiku in its default observation alongside
Sonnet and Opus. The dynamic `pstack` recommendation uses the observed canonical
IDs: Haiku for fast exploration, Sonnet for balanced implementation, and Opus
for deep analysis. All four ordered panels use Opus/Sonnet/Haiku, preserving
three worker positions.

The user's reasoning budget applies to every selected model. Haiku 5.5 supports
the reviewed effort levels; Haiku 4.5 retains `none`, meaning no native effort
override. A missing or ambiguous model family stops the three-family preset
instead of silently substituting another model. Explicit subsets and workload
choices remain supported.
If a native alias returns a different family, setup also accepts an explicitly
selected reviewed family pin and requires the observed ID to match exactly.

Same-preset reruns preserve explicit overrides, reasoning budgets and panel
order. Upgrading the plugin alone does not replace an existing model mapping;
setup previews the new recommendation before applying it. Account probes still
require authorization, and configured files do not prove runtime child effort.

The package retains 90 public Skills. Codex model recommendations, automatic
routing settings and native hook trust are unchanged.

See the [model guide](../model-configuration.md) and
[candidate checklist](../acceptance/claude-haiku-0.11.3/release-checklist.md).
Publication and local installation results are recorded separately from these
source changes.
