# Oh My Stack 0.2.0-beta.3

This beta retains all 74 directly selectable public Skills. It updates OMP
delegation guidance to the observed `proc://` lifecycle without rewriting
existing user model configuration.

Status: [public GitHub prerelease](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-beta.3).

## Changes since beta.2

- OMP background-job status, drain, and approved cancellation instructions
  use the current `proc://` interface instead of assuming the deprecated
  `hub` interface is available.
- The bounded collaboration record distinguishes observed deadline
  cancellation, controlled stale replay, isolated concurrent writers, and
  checkpoint pickup from unverified natural late delivery and live-worker
  reattachment.
- The host matrix records installed beta.3 single-route runs on both OMP and
  Codex, with explicit limits on what those runs establish.

## Verification and limits

The local beta.3 candidate passed 112 offline tests, deterministic archive
checks, and isolated OMP installation checks. Fresh installed-plugin sessions
ran one read-only `how.explorer` child on OMP and one on Codex at the configured
model and effort. The user manually confirmed a beta.3 Skill entry in the
Codex Desktop picker. This is not an automated UI trace or proof that all
Skills and panels run correctly.

The clean tagged checkout at `d74a95740050fd84f50f132d3ec9cbdc64208061`
passed the same 112 tests, a tag-bound reproducibility check, and all five
release checksums. [GitHub CI run 36121456525](https://github.com/williamwue/oh-my-stack/actions/runs/36121456525)
passed. The six published assets were downloaded again, and their five
checksummed files matched `SHA256SUMS`.

Natural late-result handling remains unverified on both hosts. OMP hard-cancel
replay and native live-worker reattachment after coordinator exit are not
claimed; validated checkpoint pickup is the recovery fallback. Authenticated
external systems, longer real-project collaboration, and Claude Code live use
remain outside this release's tested scope. Full Cursor pstack behavioral
parity is not claimed.
