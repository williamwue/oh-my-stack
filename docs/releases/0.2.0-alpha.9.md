# Oh My Stack 0.2.0-alpha.9

Status: public GitHub prerelease after the tagged release gate. This update
changes setup budget semantics; it does not claim complete Cursor parity.

## Changes since alpha.8

- Codex and OMP now interpret `small`, `medium`, and `large` as target reasoning
  efforts of `medium`, `high`, and `xhigh`. The target may raise or lower a
  route's preset effort. `unlimited` preserves the preset effort.
- If a selected model lacks the target effort, setup chooses its highest
  advertised lower effort and shows that effective choice in the preview.
- The OMP `pstack-openai-codex` alternative uses the same initial Luna, Sol,
  and Astra model/effort mapping as Codex before budget selection. OMP's
  Cursor-model `pstack` preset remains a separate option when its exact model
  identifiers appear in the live inventory.
- `--uniform-reasoning EFFORT` remains an explicit exact-effort override. It
  rejects unsupported model efforts or an effort above the selected budget.

## Setup acceptance boundary

With `--budget medium`, a fully supported OpenAI-Codex mapping targets
`high` for Luna, Sol, Astra, and all three ordered panel workers. Preview and
inspect the model inventory before applying, especially when a target model
or effort is unavailable. A written resolution proves configuration only;
fresh child runtime records are required to verify selected model and effort.

Claude Code live verification remains deferred. The OMP plugin-manager
`--dry-run` safety gap remains open; do not use it as a read-only check.
