# Oh My Stack 0.2.0-beta.2

This beta keeps all 74 public Skills directly selectable. It improves setup
receipts and owned-package maintenance without changing the user's existing
model setup automatically.

## Changes since beta.1

- Complete read-only setup receipts report all workloads, seven canonical
  roles, 16 single routes, four ordered panels, effective scope, and the
  separate runtime-activation boundary.
- Installed setup CLI scripts resolve through symlinked plugin paths.
- The generic owned-directory installer supports `inspect` and `plan` without
  writes, and `rollback` from a retained trusted previous release manifest and
  archive. Native plugin registration remains separate.
- Negative regression checks reject missing models, unsupported efforts,
  OMP model fallback, and absent child runtime evidence. Activation checks
  still do not certify task completion.
- An [observed host matrix](../host-compatibility.md) separates confirmed
  runtime combinations from untested surfaces.

## Verification and limits

On 2026-09-25, the source tree passed `npm run check` with 111 tests,
including deterministic release bytes and the new maintenance and negative
regressions. All five release checksums passed. The beta.2 OMP package passed
the native isolated-profile install, doctor, Skill load, and cleanup gate;
the Codex package passed owned-directory install and exact file verification.
These are package checks, not new model-facing worker runs. The user confirmed
the desktop Skill-selection task. Earlier
bounded OMP/Codex read-only single-worker and three-worker panel runs remain
the positive runtime evidence; they are not evidence that every workflow has
been exercised on beta.2. Real collaboration cancellation/recovery,
authenticated external integrations, and Claude Code live use remain deferred.
Full Cursor pstack behavior parity is not claimed.

For tagged-build and native installation evidence, consult the
[release process](../release-process.md) and [project status](../project-status.md).
