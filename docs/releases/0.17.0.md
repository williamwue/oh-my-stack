# Oh My Stack 0.17.0

This release adds explicit T3 Code orchestration to the source build. Generate
selected Codex or Claude Code packages with:

```bash
node tools/generate.mjs --orchestration t3 --output-root .tmp/t3
```

The selected package uses T3's actual provider/model catalog and delegated-task
API. It preserves complete role briefs, ordered panels, typed model options,
project-before-user configuration and stable retry identities. Observation
keeps requested targets separate from reported models and later child work.

An optional selection policy declares ordered cross-family trail-review
candidates, explicitly allowed same-family fallback channels and panel family
minimums. Every required seat is checked for executability, including inherited
seats. Unknown families and unavailable required reviewers block preparation.
Configured candidate order expresses preference, not benchmarked model quality.

Default release archives and the stable marketplace retain native runtime
bindings. T3 builds are an explicit source-build choice, not an automatic switch
for existing installations. Provider activation, model mappings, routing
settings and native hook trust remain user-controlled. See
[T3 orchestration](../t3-orchestration.md).

The release also removes a macOS dynamic-library dependency from the executable
pinning test while preserving rejection after executable replacement. Source
checks, independent review and local installation evidence are recorded in
[the closeout](../acceptance/2026-10-14-cross-model/closeout.md). These observations
are source and installation evidence, not universal new-session workflow or
backend option-enforcement certification.
