# Oh My Stack 0.2.0-alpha.5

Status: [public GitHub prerelease](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-alpha.5)
on 2026-09-23. Tag `v0.2.0-alpha.5` points to `f95421e35def0941fad48a7308ef6ac5218ad868`.

## Changes since alpha.4

- The default Codex plugin and standalone packages expose all 74 public
  Skills directly: 51 workflows and 23 principles. Twenty-five upstream
  workflow gaps identified after alpha.4 have portable implementations and
  explicit routes through `poteto-mode`. The 12 internal probes remain out
  of public packages.
- Codex keeps short discovery descriptions without truncating the full
  instructions of long Skills. The same canonical source generates OMP,
  Codex, and Claude Code packages.
- Reviewed newer pstack changes informed revision-bound `swarm` receipts,
  code-ready and changed-patch review rounds in `autopilot`, and no-truncate
  decision-log initialization. Host-specific model IDs and permissive
  merge exceptions were deliberately not copied.
- Package validation, provenance and MIT notices, direct-entry documentation,
  and rollback/integrity checks were expanded.

## Verified before publication

- `npm run check`: deterministic generation and release, 12 conformance
  records, Markdown lint, schema and provenance checks, and 86 passing tests.
- All four release archives and the manifest passed `SHA256SUMS`; the Codex
  plugin archive contains 74 public Skill files and zero internal probes.
- The installed local Codex candidate exposed 74 enabled Skills; eight
  read-only app-server turns selected every complete body. OMP 18.2.10
  natively read all 74 public bodies. Twelve paired read-only decision
  scenarios passed their fail-closed expectations, and a local-history `why`
  run cited the actual design commits.
- OMP's normal profile drained a two-worker coverage batch with one expected
  `BLOCKED` result and confirmed cancellation of one bounded read-only worker.
- The user confirmed `$how` and `$swarm` were visible and selectable in Codex
  Desktop. This is user-reported UI evidence, not agent-observed screen proof.
- A temporary clean checkout of the intended tree passed `npm ci`, the full
  check, release build, and checksums. The final tag-bound reproducibility
  check and build passed with `cleanTaggedCheckout: true`; all published
  archives and the release manifest passed `SHA256SUMS`.

## Known boundaries

- OMP 18.2.10 `plugin link --dry-run` still writes a user plugin link and lock
  entry. The disposable probe was removed and prior plugin state restored.
  Treat actual OMP installation as a mutation; do not use `--dry-run` as a
  safety preflight.
- Native loading and read-only fixtures do not prove every Skill's successful
  real-project behavior. Hosted PR/CI/merge, long-running recovery, authenticated
  Benny and webhook integrations, complete multi-model diversity, and Cursor
  host-specific features remain outside this release's verified claim.
- Claude Code is generated and statically checked, but live authentication and
  runtime use are deferred until the user has an account.
- This is a semantic port with deliberate host adaptations, not line-by-line
  or full behavioral parity with Cursor pstack.
