# Oh My Stack 0.2.0-alpha.1

This local Alpha release candidate adds a first-class Codex plugin marketplace
bundle without changing the 49-public-Skill workflow set introduced in
`0.2.0-alpha.0`. No public tag or hosted release is implied by this document.

## What changed

- Added a deterministic Codex marketplace archive with the generated plugin at
  `plugins/oh-my-stack/`.
- Added `.agents/plugins/marketplace.json` with explicit local source,
  installation, authentication, and category metadata.
- Kept both the portable root `plugin.json` and the supported
  `.codex-plugin/plugin.json` compatibility manifest.
- Bound the plugin and marketplace archive to the same project version,
  generated file inventory, release manifest, and SHA-256 checksum gate.
- Added exact-copy tests so the marketplace plugin cannot drift from the
  standalone generated Codex package.
- Verified the native lifecycle on Codex CLI 0.155.1 with an isolated
  `CODEX_HOME`: marketplace registration, discovery, install, exact-tree
  comparison, reinstall, uninstall, and marketplace removal all passed.

## Release artifacts

`npm run release:build` creates:

- `oh-my-stack-omp-0.2.0-alpha.1.tar.gz`;
- `oh-my-stack-codex-0.2.0-alpha.1.tar.gz`;
- `oh-my-stack-claude-code-0.2.0-alpha.1.tar.gz`;
- `oh-my-stack-codex-plugin-0.2.0-alpha.1.tar.gz`;
- `release-manifest.json` with runtime and plugin-bundle inventories;
- `SHA256SUMS` for all archives and the manifest.

## Codex installation

Extract the plugin archive, then run:

```bash
codex plugin marketplace add /absolute/path/to/oh-my-stack-marketplace
codex plugin add oh-my-stack@oh-my-stack
```

Start a new Codex task after installation. Registration and installation remain
explicit user actions; building or extracting the archive does not modify Codex
configuration.

## Verification boundary

The marketplace lifecycle verifies packaging, discovery by the plugin manager,
installation, upgrade, and removal on the recorded Codex CLI surface. It does
not broaden the workflow evidence inherited from `0.2.0-alpha.0`. Claude Code
runtime verification remains deferred, and authenticated external-system W4
behavior remains outside this release gate.
