# Oh My Stack 0.2.1

Published on 2026-09-28 as a non-prerelease:
[v0.2.1](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.1).
The tag points to `9169cfe0b924508e42a57992512fe1f66e260458`.

This patch release fixes Windows validation and test execution and adopts two
upstream workflow requirements. The catalog remains at 74 public Skills across
Codex, OMP, and Claude Code.

## Changes

- Resolve manifest references and evidence paths consistently on Windows,
  preserve containment checks, and prune dependency directories before traversal.
- Keep tracked text in LF form so frontmatter and pinned source hashes survive
  Windows checkouts. Fix shell invocation, npm lifecycle testing, temporary home
  isolation, and Markdown glob quoting on Windows.
- Reject symbolic-link output paths in the Claude effort hook. This check does
  not promise atomic path protection against concurrent filesystem changes.
- Preserve executable shell entrypoints in archives built on Windows. When
  verifying installed files, Windows compares paths, sizes, and SHA-256 hashes;
  Unix execute bits are not observable there. POSIX verification still checks modes.
- Require attributable boundaries when several runs share a decision log and
  an exact remote revision lease when rewriting an owned branch.

The [acceptance record](../upstream-and-project-acceptance-2026-09-28.md) contains
all 33 upstream decisions, independent architecture and code reviews, local Git
experiments, measured directory traversal, and frozen fishspeech visual captures.
The measured traversal improvement applies to that operation, not the entire CLI.
