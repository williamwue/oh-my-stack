Rollback therefore reinstalls from preserved source, not from the removed cache.

## Use and rollback

Start a new Codex task to pick up the updated Skills. Existing tasks may retain
older loaded instructions. Desktop picker rendering and clicking remain
unverified; native protocol checks do not substitute for that UI claim.

To restore the published alpha.4 on this machine:

```bash
codex plugin marketplace remove oh-my-stack
codex plugin marketplace add "$HOME/.local/share/oh-my-stack/releases/v0.2.0-alpha.4/oh-my-stack-marketplace"
codex plugin add oh-my-stack@oh-my-stack
```

Then start another new task. This removes only the selected marketplace
registration before registering the preserved source again. The rollback
source passed integrity checks; rollback was not executed during acceptance.

To return to this candidate, use the same remove/add/reinstall sequence with
the candidate marketplace root recorded below relative to the home directory:

`.local/share/oh-my-stack/releases/local-long-skills-orbSYK/oh-my-stack-marketplace`
