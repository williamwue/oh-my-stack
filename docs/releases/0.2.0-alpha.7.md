# Oh My Stack 0.2.0-alpha.7

Status: [public GitHub prerelease](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-alpha.7).
This is a semantic pstack port with runtime-specific adaptations, not a claim
of complete Cursor behavioral parity.

## Changes since alpha.6

- OMP setup retains the Cursor-style `pstack` preset and adds an explicit
  `pstack-openai-codex` alternative when its GPT-6 Luna, Sol, and Astra IDs
  are all present in the live OMP inventory. It proposes Luna for fast work,
  Sol for routine coding, Astra for deep work, and ordered Astra/Sol/Luna
  panels. It does not silently substitute GPT-5.5 or apply a new mapping
  without review.
- Switching OMP presets requires explicit review of the budget and prior
  overrides. The setup instructions show model and cost tradeoffs and stop
  when a required model is absent.
- The Codex setup strategy is unchanged from alpha.6. This release includes
  the complete Codex marketplace bundle so users can test that setup in a
  current plugin installation rather than an older cached version.

## Verification

- The source checkout passed generation, conformance, reproducible release,
  repository validation, Markdown lint, and all 98 automated tests.
- In one project-scoped OMP 18.2.11 read-only probe, a fresh task selected
  `ohmystack-how-explorer` from the project agent directory. Runtime task
  metadata resolved `openai-codex/gpt-6-luna:high` without fallback.
- The other OMP routes and the Codex alpha.7 setup experience have not been
  independently live-tested for this release. Generated files alone do not
  prove runtime model selection.

## Known limits

- The OpenAI-Codex alternative is a provider-specific proposal, not a claim
  that its models are equivalent to Cursor's models. Astra can cost more than
  Sol or Luna. All three choices currently use one provider, so the ordered
  panels do not establish cross-provider diversity.
- OMP `plugin link --dry-run` has previously written user plugin state; do
  not treat it as a read-only preflight. Codex generated custom-role TOML is
  not evidence that a tested CLI selected those roles; delegated work uses
  explicit model and reasoning settings.
- Hosted PR/CI/merge, long-running recovery, authenticated Benny/webhook
  integrations, and Claude Code live use remain outside this release's
  verified claim. Claude Code awaits an authenticated local runtime.
