# Oh My Stack 0.2.0-alpha.0

This local Alpha release candidate extends the shared portable source to 49
public Skills and 12 internal runtime probes. It produces OMP, Codex, and Claude
Code packages from one source version. No public tag or hosted release is
implied by this document.

## What changed

- Added graduated `babysit`, `pause-safely`, `session-pickup`,
  `autonomous-run`, `shipping`, `orchestrate`, `autopilot-stack`, and
  `autopilot-full` workflows.
- Added the fail-closed Benny pack: `setup-benny`, `triage-issue-reports`, and
  `reproduce-and-fix-issues`.
- Added a Codex Desktop scheduled-wake observation and OMP/Codex safe
  no-scheduler fallbacks.
- Refreshed the complete public-Skill delivery matrix on OMP 18.2.8 and Codex
  CLI 0.155.1.
- Preserved exact upstream snapshots, per-file ownership, semantic derivations,
  and MIT notices for the imported Benny source.

queue, deployment, or other W4 completion.

## Release artifacts

`npm run release:build` creates:

- `oh-my-stack-omp-0.2.0-alpha.0.tar.gz`;
- `oh-my-stack-codex-0.2.0-alpha.0.tar.gz`;
- `oh-my-stack-claude-code-0.2.0-alpha.0.tar.gz`;
- `release-manifest.json` with exact file inventories and maturity labels;
- `SHA256SUMS` for all archives and the manifest.

The archives contain no runtime credentials, live transcripts, conformance
evidence, repository tools, or user configuration.

## Security and trust

Installation remains dormant. It does not create or enable Benny automations,
connect a communication or tracker provider, capture media, open a pull request,
merge, deploy, install an MCP server, or register a Hook. Those operations need
separate reviewed runtime configuration and the capabilities required by each
Skill.

The default packages contain Skills, generated role definitions, model setup
scripts, and one Skill-local shell helper. The release installer verifies
archive safety and checksums but never executes packaged scripts.

## Known limits

- Claude Code discovery and workflow behavior remain deferred by explicit
  project decision until an authenticated local runtime is available.
- OMP native plugin-manager D1 remains unresolved because its observed dry-run
  path mutated state; artifact lifecycle success is not substituted for that
  gate.
- Codex IDE has no live runtime evidence, and Codex Desktop evidence is limited
  to the scheduled-wake slice.
- External-system W4 behavior for Benny and the advanced forge workflows is not
  established by their deterministic local providers.
- Generated custom-role selection is unavailable on the observed Codex CLI
  spawn surface, so bounded inline role contracts remain its verified fallback.
