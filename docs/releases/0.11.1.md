# Oh My Stack 0.11.1

This release makes optional Codex automatic routing a choice in
`setup-oh-my-stack`. Select the setup Skill and submit its default prompt;
you no longer need to compose an instruction to enable routing.

Setup shows the current effective setting and offers enable, disable, or keep
current settings. For a change, choose a personal default across projects or
only the current project. Completing those selections saves the setting without
asking you to repeat the activation request. Existing project overrides retain
priority, and setup reports them separately from the personal default saved.

Routing choices preserve model mappings and hook trust. Model setup is offered
separately and can be skipped without inventory collection or worker probes.
Explicit mode/scope requests and read-only status or preview requests still work.

The interface uses native choice controls when the host and current mode expose
them, otherwise explicit text choices. The isolated Codex 0.160.1 default-mode
run used text choices. Structured native questions were observed with
`default_mode_request_user_input` enabled only in a disposable app-server process;
this release does not turn on experimental host features in a personal profile.

Manual routing remains the installation default. When enabling routing, review
the OMS hook through native `/hooks` and verify a new session. Saving a switch
does not establish hook execution or automatic workflow selection. Claude Code
and OMP retain their model setup and explicit engineering entries; this patch
does not add automatic routing support for them.
