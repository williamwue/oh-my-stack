# Oh My Stack 0.2.0-alpha.6

Status: [public GitHub prerelease](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-alpha.6).
This is a semantic pstack port with runtime-specific adaptations, not a claim
of complete Cursor behavioral parity.

## Changes since alpha.5

- OMP keeps native project roles and adds upstream-style code and reflection
  slots, ordered model panels, target-effort budgets, and retained explicit
  choices on setup re-runs. Configuration remains project-scoped, not a
  Cursor-style global always-applied rule.
- Codex delegated workflows derive explicit spawn-time model and reasoning
  settings with the complete role task contract. Generated custom-role files
  remain reference artifacts on the probed CLI; they are not described as
  activated roles.
- The source, generated packages, model-routing tests, capability records,
  executable inventory, and provenance hashes are updated together.

## Verification

- A clean detached checkout passed `npm ci --ignore-scripts`, `npm run check`
  with 97 tests, reproducible release build, and checksums for the four
  archives and release manifest. The final `v0.2.0-alpha.6` tag-bound gate also
  passed with `cleanTaggedCheckout: true`.
- OMP 18.2.10 selected all six new routes in bounded read-only tasks with
  attributable child roles, non-fallback models, and expected effort. An
  unobserved model was rejected without changing the existing manifest.
- Codex CLI 0.155.1 independently recorded explicit child model and effort
  for the tested route. Its persisted spawn message was encrypted, so the
  exact transmitted role text was not independently compared with the
  prepared request.

## Known limits

- Route smoke tests do not prove complete feature, bug-fix, performance,
  hillclimb, or reflection workflows. A Luna override run selected and
  injected its role correctly but did not reliably report the policy marker;
  the default Opus rerun did.
- OMP 18.2.10 `plugin link --dry-run` can write user plugin state. Do not use
  it as a read-only preflight. The local development plugin is already linked
  to this repository, so regenerating its package changes what it loads.
- Hosted PR/CI/merge, long-running recovery, authenticated Benny/webhook
  integrations, distinct provider backends, and Claude Code live use remain
  outside this release's verified claim. Claude Code runtime verification is
  deferred until an authenticated local account is available.
