# Oh My Stack 0.5.0

Prepared on 2026-10-03 as the authorized continuation of the GitHub acceptance
and release work. This release adds an explicit single-maintainer review
policy to the Codex GitHub provider and workflow binding. The public catalog
remains 74 Skills across Codex, OMP and Claude Code.

## Behavior

`reviewPolicy: "independent-oms"` accepts a frozen independent OMS reviewer
session with passing verification, root authorization and a countersigned
current-bottom PR. The default remains `github-review`, requiring a separate
GitHub approval. A repository's configured GitHub approval requirements are
never replaced by OMS evidence.

The new policy audits classic protected branches with strict named CI checks,
positive GitHub App source IDs, administrator enforcement, and no force pushes
or deletion. Active rulesets, code-owner review and last-push approval policies
are currently unsupported and stop safely. Missing or unknown policy is not
interpreted as permission. Review comments do not erase earlier decisive
approval or changes-requested states.

Both the workflow and direct provider validate scoped evidence. Merge inputs
are snapshotted before asynchronous work; journal identity binds the policy.
Recovery uses the original operation and policy, with no repeated remote
mutation. Old default-policy journal recovery remains supported.

## Limits and release gates

Session evidence remains a caller assertion, not authenticated consent or a
cryptographic signature. The GitHub merge API cannot atomically guard the base
SHA. Explicit server-policy authorization retains this race; strict target
CAS and full unattended queue operation remain unsupported.

The release requires independent source review, focused provider/workflow
checks, the full repository gate, deterministic clean tagged builds, and
passing remote CI. Hosted evidence must separately establish normal merge and
operator-assisted recovery after a real process kill. Installer lifecycle and
native plugin registration remain distinct from those workflow claims.

Before publication, install/update/rollback/verify all three runtime archives,
run the isolated native OMP package check, then download all published assets
and compare them with the trusted tagged build. Model routing and unrelated
workspace files must be preserved during any installed-plugin upgrade.

## Candidate evidence

[Hosted acceptance](../github-single-maintainer-acceptance-2026-10-03.md)
passed normal merge and operator-assisted recovery after an accepted merge
followed by SIGKILL. Each scenario issued exactly one merge PUT. Both landed
commits were verified on the protected target. The default review policy still
blocked the same unapproved fixture; only the explicit OMS policy admitted it.

Independent code review passed after fixing a missing check-source validation
finding. The focused suite passed 35 tests; the complete repository gate passed
227 tests. Three runtime archives passed install/update/rollback/verify in
isolated directories, followed by updated-candidate verification. The isolated
native OMP gate passed installation, doctor, Skill loading and cleanup. These
are candidate receipts; tagged source, remote CI and downloaded-asset evidence
are recorded by the publication receipt.
