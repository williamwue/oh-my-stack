# Oh My Stack 0.4.0

Release prepared on 2026-10-03. The user explicitly requested
completion of version publication in this session.

This minor release adds a real GitHub provider and packaged Codex bindings
for one PR: opening-a-pr creation, babysit check, and root-authorized shipping.
The public catalog remains 74 Skills for Codex, OMP and Claude Code. The new
GitHub binding is Codex-specific; other runtime packages retain their existing
workflow behavior.

## Behavior and limits

The provider uses the maintainer's native official gh login, verifies exact
account and repository, journals intent before mutation, and reconciles
uncertain outcomes through remote readback. Workflow authorization binds
branch names, revisions, operation, patch and target policy. Independent OMS
review and a current GitHub approval are separate requirements. These local
records are caller assertions, not authenticated consent.

Strict atomic target-revision merging is unsupported and stops. Ordinary
server-policy merging requires explicit authority and retains the race between
the final base read and server merge. No automatic queue, background repair,
worker reattachment or new scheduler is introduced.

[Hosted acceptance](../github-hosted-acceptance-2026-10-03.md) passed real PR
creation, deliberate CI failure/repair and operator-assisted recovery after an
actual SIGKILL. No independent GitHub approval account was available; that
fixture PR remains unmerged. Live merge and interrupted-merge recovery remain
unverified. This does not prevent publishing the disclosed experimental
interface, and publication does not upgrade that acceptance claim.

[Source integration](../github-workflow-acceptance-2026-10-03.md) records the
independent implementation review and race/evidence fixes. Fresh release
checks apply to the frozen release commit rather than reusing that result.
Book translations landed separately through PR 2 while this release was being
prepared. They are retained unchanged from the refreshed main baseline; the
GitHub runtime archives do not bundle those source documentation files.
Existing management metadata commits are included as release prerequisites;
historical reports retain their original bytes.
