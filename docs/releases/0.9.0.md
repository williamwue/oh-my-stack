# Oh My Stack 0.9.0

This version adds five complete Matt Pocock originals to released 0.8.0:
`grill-me`, `grilling`, `domain-modeling`, `grill-with-docs`, and
`improve-codebase-architecture`. The catalog has 84 public entries:
60 workflows and 24 principles, plus 12 internal probes.

## Original capabilities

All six selected AIHero skill directories are pinned at
`mattpocock/skills@6fd947921b935b7e1e69293a200400f0fdd5c15f`, including
original invocation metadata, references, templates, UI metadata and MIT
license. The original Skill-tool dependency names are preserved. No source
text adaptation, OMS workflow fusion or model delegation binding is injected.

The import includes complete dependencies: `grill-me` invokes `grilling`;
`grill-with-docs` invokes `grilling` and `domain-modeling`; architecture review
uses the existing original `codebase-design`, `grilling`, `domain-modeling`,
and its complete HTML reference. Existing pstack skill files remain unchanged.

## Acceptance and gates

See the [usage guide](../aihero-original-skills.md),
[bounded live acceptance](../aihero-original-0.9.0-acceptance.md), and
[candidate checklist](../acceptance/aihero-0.9.0/README.md).
Original-file hashes are validated across Codex, Claude Code and OMP.
Codex project-local selection and Claude's native session-plugin slash entry
are exercised separately. A finished CLI turn alone is not workflow acceptance:
resource reads, question rounds, actual document/report writes, and stopping
before implementation must be inspected.

The local Markdown-link validator now excludes literal fenced templates from
link resolution, while preserving checks for real links and repository escapes.
This supports the original glossary examples without editing upstream documents.

Publication requires independent frozen-candidate review, fresh GitHub CI,
clean tagged checks, deterministic builds and downloaded-asset comparison.
Native Codex installation and dependency resolution are a separate gate;
Desktop picker interaction and live OMP behavior are not claimed.
The architecture HTML uses the upstream CDN styling and diagram dependencies.
`to-spec`, `to-tickets`, tracker setup and broader AIHero workflows are deferred.

Publication status is recorded in the
[GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.9.0).
Native managers determine installed versions.
