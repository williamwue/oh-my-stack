# Oh My Stack 0.13.0

Five original AIHero Skills complement the pstack workflows:

- `writing-for-agents` adds a shared reference for agent-consumed documents.
- `retro` proposes project-environment improvements from a session.
- `handoff` exports a portable, redacted handoff file.
- `diagnosing-bugs` provides a reproducible diagnosis, fix, and cleanup loop.
- `code-review` reports Standards and Spec findings separately.

There are now sixteen AIHero originals and 95 public entries: 71 workflows and
24 principles. All three target packages preserve the original resources,
license, and source coordinates. The first fourteen originals remain pinned;
the two newer engineering entries use a separate immutable source revision.

See the [AIHero guide](../aihero-original-skills.md) for selection and limitations.
The review's original three-dot diff excludes uncommitted edits. Its two-axis
review requires actual parallel reviewers; the optional HITL diagnosis template
requires Bash and tailored reproduction steps. Existing OMS routing and model
settings are preserved.

The pinned local maintainer pipeline now supports Windows npm and Python layouts.
Windows fixture launching, quoted routing paths, and the local stable-promotion
test are fixed without skipping the relevant checks. Prior dated failure and
discovery receipts remain historical evidence.

Source and metadata discovery establish packaging and entry availability.
They do not establish complete long-entry injection, automatic selection quality,
or the execution quality of every new workflow. Update the existing native
installation and start a fresh session; model configuration remains separate.
