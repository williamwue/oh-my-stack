# Oh My Stack 0.15.0 candidate

This candidate ports the reviewed pstack 0.15.14–0.15.17 changes into the
portable Codex, OMP and Claude Code packages. The
[upstream record](../upstream-pstack-0.15.17.md) pins the source and accounts
for every changed file.

`ketchup` catches up on this chat and pending human decisions without starting
work. Help offers relevant missing model setup once per chat and answers the
original question without running setup. Prose updates retain OMS 0.14's
configured design panels, independent judgment and frozen delivery checks.

Fresh model configuration defaults to large (xhigh); explicit unlimited targets
max with a supported lower-effort fallback on the same model. Existing effective
choices and ordered panels survive a same-preset rerun. The updated two-model
Cursor preset does not replace saved panels or the Codex, Claude and OMP
OpenAI-Codex model mappings. See [model configuration](../model-configuration.md).

This is a local candidate. Building and checking it does not publish a release,
change personal model settings, or activate it in an existing conversation.
Native host availability and recorded task attribution are reported separately
from generated-package and local-test results. Encrypted assignment records
cannot satisfy full delivery attribution.
