# Oh My Stack 0.2.0-alpha.10

This update adds reusable user-level setup for OMP
and Codex, and closes the six named-route configuration gaps on Codex. It does
not claim complete Cursor pstack parity.

## Changes since alpha.9

- Setup defaults to the runtime's user scope: `~/.omp/agent/` on OMP and
  `~/.codex/` on Codex. `--project-root` creates a complete project override;
  `--output` remains a detached destination. Existing project manifests are
  not removed or changed by user setup and keep taking precedence. User-level
  canonical roles use `ohmystack-role-*` names to avoid replacing general
  personal or bundled task agents.
- Workflows resolve the nearest project manifest first, then the user default.
  Codex explicit delegation uses the same lookup and records which scope it
  selected. Codex user-level TOML is still a configuration artifact, not proof
  of native custom-agent selection on the tested CLI surface.
- Codex adds independent `code.feature-refactoring`, `code.bug-fix`,
  `code.perf-issue`, `code.hillclimb`, `reflect.divergent`, and
  `reflect.synthesizer` routes. `code.delegates` remains available to older
  callers. Re-running the same Codex preset preserves recorded choices.
- A two-project fixture checks inheritance, one-project override, rerun
  preservation, and explicit Codex model routing. Invalid project manifests
  and unowned personal-agent collisions fail closed.

## Verification boundary

Static generation, release reproducibility, repository validation, and the
automated test suite pass. The fixture uses disposable directories and observed
model IDs supplied by tests; it does not prove a fresh OMP or Codex session
selected a user-level role, nor that every route ran on its configured model.
The previous OMP plugin-manager safety gap and Claude Code live-verification
deferral remain unchanged. Before testing alpha.10 in an existing project,
inspect its project manifest: that manifest intentionally wins over the new
user default until the project is reconfigured or its override is explicitly
removed.
