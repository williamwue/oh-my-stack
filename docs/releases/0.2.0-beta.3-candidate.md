# Oh My Stack 0.2.0-beta.3 local candidate

This is a local acceptance candidate, not a published release or Git tag.
The public baseline remains [beta.2](0.2.0-beta.2.md).

## Changes since beta.2

- OMP delegation instructions use the observed 18.3.0 `proc://` background-job
  lifecycle for status, drain, and approved cancellation instead of assuming
  the deprecated `hub` tool is present.
- The [bounded collaboration record](../bounded-collaboration-acceptance-2026-09-25.md)
  now separates passing deadline cancellation, controlled stale replay,
  isolated concurrent writers, and checkpoint pickup from unverified natural
  late delivery and live-worker reattachment after coordinator exit.
- The generated target packages retain all 74 public direct Skill entries;
  no existing user model configuration is migrated by installing the plugin.

## Candidate gate

Before any public tag, require a clean source checkout, `npm run check`,
reproducible archives and SHA-256 verification, OMP and Codex native plugin
loading in fresh sessions, and a bounded model-facing worker run on each host.
Record exact versions and observed worker model/effort. Keep the previous
versioned package directories for rollback. Claude Code live use remains
deferred until an authenticated runtime is available.
