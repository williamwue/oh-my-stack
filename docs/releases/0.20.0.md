# Oh My Stack 0.20.0

OMS follows official pstack 0.15.30 at
`4ec7ffa173eaa70d3d9467a627baf0954645a353` as its primary baseline and tracks
pstack-claude at `356c6e0f978df729eb16f227d795f34d221c5aad` as a secondary
implementation and policy reference. The default distribution has 81 public
Skills: 57 workflows and 24 principles.

## Changes

- Add formal verification creation and maintenance, TLA+ statecharts and the
  updated official catch-up, prompt and verification guidance.
- Track both references through bounded read-only update planners, fixed source
  receipts, 31 adoption decisions and coverage of 229 current modules / 764
  source files. Review all active modules instead of relying only on recent
  deltas; preserve intentional native-host and authorization differences.
- Parse rendered Markdown link destinations, preserve private HEAD-reflog-only
  history, locate Claude transcripts by session identity and bound collector
  child termination, pipe draining, pagination and output.
- Share native Codex/Pi configuration-home lookup. Bind Claude retry adjustments
  to saved requests, task/scope identity and original/current capability checks.
  Strengthen executable discovery and frozen-harness path validation.
- Use a pinned licensed parser with fence source maps for plan checks. The
  generated helper runs without an external parser installation on Node or Bun.
- Show readable routing configuration and proposed effective state, including
  nearer project overrides. Show readable worktree verdicts and evidence reasons
  while retaining conservative advisory status and cleanup authority.
- Record autopilot's merge-ready or merged target under existing authority,
  program concurrency and repair history. Publish a compact shared resume state
  and grouped Skill navigation without hiding public principles.

## Validation and boundaries

The [module audit](../acceptance/2026-10-23-module-review/result.md) records scoped
independent review and isolated generated-helper/Node/Bun acceptance. The
[strategy verification](../acceptance/2026-10-23-strategy-ux/result.md) records
988 source tests: 948 pass, zero failures and 40 prerequisite skips before
release preparation. The tagged maintainer pipeline separately reruns the full
checks with the pinned Node 22.23.3 and zlib 1.3.1-e00f703, audits bilingual book
sources, verifies reproducible builds and checks all eight uploaded/downloaded
release assets before stable promotion.

Default archives retain native bindings. T3 + AIHero remains an explicit
source-build selection. Installation preserves personal routing/model settings;
publishing does not install a plugin or run model setup.

Actual Claude Code account/session dispatch, model-option enforcement and live
cross-family Trail review remain unverified and are not publication claims.
The earlier Pi acceptance used a local simulated provider. Copilot, Muse and
Pi questions, wakeups and loop tools remain unscheduled TODOs. Existing user
authorization, review/verification gates and conservative worktree retention
remain in force; this release does not restore an independent-review parameter
to the local publisher or require CI as a publication authority.
