# Oh My Stack 0.3.0

Release candidate prepared on 2026-09-30.

This minor release introduces six local source capabilities: durable run
recovery, a disposable autopilot provider, runtime matrices, revision-bound
receipts, concurrent-writer protection and bounded probes, and a read-only
operations doctor. The catalog remains 74 public Skills for three runtimes.

Use a source checkout for the new tools; the runtime archives do not install
them as global commands. See the [operations guide](../operations-guide.md).

## Acceptance scope

The integration at 925eb7d passed 179 tests and independent unit reviews.
Windows Node and Bun probes and the local doctor passed. Revision-bound
receipts from that integration do not automatically attest this release commit.
Release gates require fresh checks, deterministic tagged builds, remote CI,
and downloaded-asset and installed-inventory verification.

The user authorized publication on 2026-09-30. Hosted autopilot, native POSIX
workflow acceptance and FishSpeech authenticated backend checks remain
explicitly deferred. FishSpeech desktop/mobile rendering and screenshots
passed; menu/tab interaction acceptance is incomplete. Fresh authenticated
Codex, OMP and Claude workflow smokes are not claimed. Historical runtime
conformance keeps its original revision and scope. Full pstack parity is
not established. Local locking supports cooperative local filesystem writers,
not distributed locks or live-worker reattachment.
