# Oh My Stack 0.10.0

This version adds original AIHero research and planning skills and a stable
installation and update path for Codex and Claude Code.

## Original AIHero capabilities

Adds five original Matt Pocock skills: `research`, `to-questionnaire`,
`setup-matt-pocock-skills`, `to-spec`, and `to-tickets`.
The package includes eleven original AIHero skills and 89 public entries
(65 workflows and 24 principles). Original bodies, resources, invocation modes,
and MIT licensing retain the existing pinned upstream revision.

Use [the AIHero guide](../aihero-original-skills.md) for project setup,
local spec and ticket paths, and confirmation steps. The originals remain
independent entries; they do not automatically enter OMS implementation or
release workflows. No original workflow instructions or model routes are
redesigned by this release.

## Installation and updates

- Bilingual README and guides provide copyable agent installation, read-only
  update-check, and update prompts.
- New installations can use the verified `stable` Git marketplace. Published
  archives remain available; existing archive users keep their source type
  unless they deliberately migrate.
- Native update instructions preserve installation scope, other plugins,
  project files, and model mappings, and include version/cache checks and rollback.
- A publication workflow promotes only verified formal releases to `stable`,
  after checking exact source CI, all asset digests and inventories, and a clean
  tagged rebuild. Version rollback and concurrent branch replacement are refused.

## Verification and boundaries

The [release checklist](../acceptance/aihero-0.10.0/release-checklist.md) names required gates.
The dated [original-workflow acceptance](../aihero-original-0.10.0-acceptance.md)
records five bounded fixtures per host, including approval-sensitive writes and
background research. The [channel bootstrap acceptance](../acceptance/2026-10-07/stable-marketplace.md)
records the initial 0.9.0 to 0.9.1 update, migration, and rollback observations.
These historical records retain their original candidate/version scope.

Complete original-byte validation, package generation, deterministic archives,
Markdown checks, 256 repository tests, and the bilingual book audit are required.
Desktop/IDE interaction, OMP original-workflow execution, automatic-update UI,
and real remote tracker publication are not certified by these CLI fixtures.
A running agent session may keep the old plugin; use a fresh session after
updating and select `prove-it-works` for a read-only loading check.

Actual publication status and assets are recorded by the
[GitHub release](https://github.com/williamwue/oh-my-stack/releases/tag/v0.10.0).
