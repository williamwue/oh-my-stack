# Oh My Stack 0.9.1

This release makes the documentation easier to use from a first installation.
The English homepage now leads with installation, a read-only first task,
and common task entries. A Chinese README and matching user guides cover the
same steps. Building the source is no longer the default onboarding path.

## User documentation

- Separate installation guides for Codex, Claude Code, and OMP distinguish
  terminal management commands from Skill requests sent in a conversation.
- First-task, common-task, AIHero, model configuration, update/removal, and FAQ
  guides explain expected results and possible file changes.
- The support policy separates recorded native installation, session-plugin
  fixtures, and unverified surfaces. Previous maintainer narratives remain
  archived with their original version scope.

## Directory maintenance

The Skill directory is generated from the packaged public catalog and actual
Skill descriptions. `npm run docs:generate` refreshes it, and `npm run docs:check`
rejects drift without rewriting the document. The check is part of CI.
The package still contains 84 public entries: 60 workflows and 24 principles.

## Scope and verification

Workflow instructions, scripts shipped to users, selected AIHero original
resources, and source pins retain the 0.9.0 content. Package version metadata
is regenerated at 0.9.1. Model configuration is separate and is not reset.

The [candidate checklist](../acceptance/docs-0.9.1/README.md) records the release
gates. Existing 0.9.0 live observations are explicitly historical; this patch
does not claim new model-facing workflow acceptance, desktop interaction, or
first-time human usability testing.
