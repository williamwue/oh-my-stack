# Oh My Stack 0.2.0-alpha.4

This unreleased Alpha reduces the default Codex Skill-catalog footprint while
preserving the complete portable workflow set.

## What changed

- The Codex marketplace plugin exposes four primary entrypoints:
  `bug-fix`, `poteto-mode`, `prove-it-works`, and `setup-oh-my-stack`.
- The other 45 public workflows remain in the plugin under `library/skills/`.
  They are not scanned into the initial Skill catalog; `poteto-mode` reads the
  selected workflow after routing.
- The standalone Codex archive, OMP archive, and Claude Code archive continue
  to contain all 49 public Skills.
- The 12 internal `check-*` probes remain test-only and appear in neither the
  compact plugin nor public archives.

## Why

Cursor pstack marks most Skills as explicit-only, so Cursor loads them when a
user invokes the matching slash command instead of placing every description
in normal conversation context. Codex does not currently expose an equivalent
packaging switch that removes an explicit-only Skill from its initial catalog.
The compact marketplace view provides the closest supported behavior: a small
entry surface with the full workflow library still present for on-demand use.

## Compatibility boundary

Direct invocation of every workflow remains available through the complete
Codex archive. The default marketplace plugin favors a smaller initial context
and routes advanced workflows through `poteto-mode`.
