# Oh My Stack 0.2.0-alpha.4

This Alpha keeps direct access to every public Skill while reducing
Codex discovery metadata.

## Changes

- The default Codex plugin exposes all 49 public Skills under `skills/`.
- Direct invocation and optional `poteto-mode` routing coexist.
- Codex descriptions are concise and scoped; full workflow instructions,
  references, invocation policies, and supporting resources remain intact.
- The Skill directory, generated catalogs, and Codex display names distinguish
  26 workflows and 23 principles. Skill invocation names are unchanged.
- The 12 internal probes remain test-only.
- No compact installation mode or deferred workflow library is included.

## Verification boundary

Package tests verify that every public Skill remains in the discoverable tree,
plugin contents match the standalone Codex package, categories partition the
public catalog, and descriptions preserve complete instruction bodies.
Shorter descriptions reduce metadata characters, not the number of registered
Skills or a guaranteed amount of runtime tokens. A host may still shorten its
initial list when other plugins are installed. Claude Code live verification
remains deferred.

See the [local acceptance record](0.2.0-alpha.4-acceptance.md) for native
discovery and explicit invocation evidence and the desktop UI limitation.
