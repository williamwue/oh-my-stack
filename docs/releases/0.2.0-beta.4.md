# Oh My Stack 0.2.0-beta.4

Status: [public GitHub prerelease](https://github.com/williamwue/oh-my-stack/releases/tag/v0.2.0-beta.4).

## Changes since beta.3

- Claude Code now has a repository-native marketplace and a deterministic
  marketplace archive. A plugin installed through this route persists across
  sessions, unlike the earlier `--plugin-dir` smoke test.
- Claude Code setup can use an observed two-model Sonnet/Opus mapping and
  generates native user/project roles. The bounded local `architect.runners`
  panel observed Opus/Sonnet/Opus and effective `high` effort.
- The release adds an explicit audit for generated Claude setup and hook
  records. No Haiku entitlement or fallback is assumed.
