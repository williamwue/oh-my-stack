# Install with an agent

Give your agent this request:

```text
Install the latest Oh My Stack release for my current host (Codex, Claude Code
or Pi). Follow https://github.com/williamwue/oh-my-stack/blob/main/README.md.
Preserve personal model configuration and unrelated project files. Verify the
release manifest, archive hashes, native registration and loaded version.
Restart if required, load poteto-help and report actual checks and any runtime
actions that still need verification.
```

OMP is retired from new releases. The old prove-it-works and oms-auto entries
are not included. AIHero originals are included as independent extensions.
