# codex installation

Follow the current [README](../../README.md#install) for the stable marketplace.
Use the latest released `codex` archive for offline installation with
`tools/install-release.mjs` and its matching manifest. Verify hashes before
installing into a dedicated OMS directory. Restart and verify the native plugin
version, poteto-help and standalone AIHero entries. Preserve personal upstream
model sheets; setup-pstack changes configuration only when explicitly invoked.
Live model verification remains separate from static install checks.
