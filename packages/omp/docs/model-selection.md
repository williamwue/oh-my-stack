# Model selection

Collect a current inventory with scripts/collect-model-inventory.mjs --runtime omp. Review every model and effort before scripts/configure-models.mjs --apply. Preview is the default; --output writes only a detached destination. Native scope is ~/.omp/agent and project .omp. scripts/model-resolution.mjs resolves nearest project first, then user configuration; each host owns an independent manifest. Fresh panels contain two entries. Same-target/same-preset reruns preserve saved membership, order, model and effort unless an explicit change requests otherwise. Missing observed model/effort selectors fail. Configuration artifacts do not prove native routing.

Saved personal configuration is the starting budget. Task selection does not rewrite it. Keep the configured model and family, panel membership, and order. Use only effort alternatives in the observed host inventory. Hardest work raises effort one supported level, capped at max or the highest advertised level below max. An explicitly saved effort above max remains unchanged. Judgment lowers it one level. Routine work lowers it two levels or to the lowest supported value. Verification keeps the configured model, effort, and speed. Other tasks request standard speed unless urgency calls for fast. Inherit-parent and auto aliases stay unchanged. Record the original role line, task choice, and any rejected adjustment. Requested settings do not prove backend enforcement.

For each task, inspect the native host's current typed model and effort catalog. Use the host's documented selection controls for supported adjustments. A generated agent file alone does not implement per-task overrides. If the native call cannot override a setting, report that limitation and use the saved role line. Use a speed selector only when the live host advertises it. Otherwise report speed as unsupported. After an adjusted choice is rejected, retry the original role line once and report the rejection. Do not guess another model ID.
