### Session pickup

**You own the resume point. Read the prior trail, don't redo it.**

1. Read the project-designated durable checkpoint pointer first, or `.oh-my-stack/resume.md` in the current project when no project locator is defined. Recover its objective and delivery target, current phase, latest verified checkpoint, pending handles and first next action. Confirm its workspace, task and revision, and read the requested linked questions, checklists and procedures. Diagnose an unavailable or incomplete checkpoint rather than silently treating it as complete. When no checkpoint exists, locate the prior trail. A local transcript under the active workspace's `agent-transcripts/` directory (the system prompt names the path. Do not glob across `unrelated host workspace transcript roots`, that crosses workspace boundaries and reads private chats from unrelated projects), a cloud-agent URL, or a pushed branch. Read the metadata overview and last messages first, then scan back for the decision points. Parse a long transcript in a subagent and keep the reduced timeline in the main thread (the **principle-guard-the-context-window** skill). Pick each subagent's reasoning level and fast or standard speed for the job, per the Subagents section.
2. Reconstruct operational state. The branch and worktree, what already landed (`git log`, `git diff` against the base), the open todos, the decisions made. Use the prior trail to recover progress. For human rulings, locate the attributable original wording and source. Label agent summaries and copied interpretations. If the original is unavailable, its exact scope remains uncertain. Repeated copies are one dependent evidence chain and establish neither a broader restriction nor permission.
3. Diff done vs pending. Compare what shipped against what was planned, name the resume point, do not re-run the prior repro or redo completed work. A "let me verify from scratch" pass means you're treating the trail as untrustworthy when it's authoritative.
4. Route the remaining work to the matching playbook and pick the verdict: continue the execution, ship a finished recommendation, ratify or override a prior conclusion, or postmortem a failed run. The pickup playbook ends here. The routed playbook owns the rest.
5. Verify the inherited claims against the original goal on the real artifact (the **principle-prove-it-works** skill). A passing prior self-report is not the proof.

**Reply:** where the prior agent stopped, what you inherited vs redid (ideally nothing redone), the resume point, and the outcome.
