# Model selection

Collect a current inventory with scripts/collect-model-inventory.mjs --runtime claude-code. Review every model and effort before scripts/configure-models.mjs --apply. Preview is the default; --output writes only a detached destination. Native scope is ~/.claude (or CLAUDE_CONFIG_DIR) and project .claude. scripts/model-resolution.mjs resolves nearest project first, then user configuration; each host owns an independent manifest. Fresh panels contain two entries. Same-target/same-preset reruns preserve saved membership, order, model and effort unless an explicit change requests otherwise. Missing observed model/effort selectors fail. Configuration artifacts do not prove native routing.

Saved personal configuration is the starting budget. Task selection does not rewrite it. Keep the configured model and family, panel membership, and order. Use only effort alternatives in the observed host inventory. Hardest work raises effort one supported level, capped at max or the highest advertised level below max. An explicitly saved effort above max remains unchanged. Judgment lowers it one level. Routine work lowers it two levels or to the lowest supported value. Verification keeps the configured model, effort, and speed. Other tasks request standard speed unless urgency calls for fast. Inherit-parent and auto aliases stay unchanged. Record the original role line, task choice, and any rejected adjustment. Requested settings do not prove backend enforcement.

Use scripts/claude-delegation.mjs prepare --input REQUEST.json for native Agent requests. Supply a captured Claude Code version, advertised subagent types, and model IDs mapped to native selectors and supported reasoningEfforts. Native per-call effort requires version 2.1.292 or later. The helper preserves subagent_type and passes effort directly; environment CLAUDE_CODE_EFFORT_LEVEL takes precedence. Keep the complete prepared result. After an actual adjusted-effort rejection, supply rejectedAdjustment and that result as rejectedPreparedRequest; captured capabilities validate the original request and current capabilities validate the restored selection. Verify the actual dispatch and child-ID-correlated hook record using the verify command; preparation never proves effective effort. Read docs/claude-delegation.md. T3 bindings use target.options instead.
