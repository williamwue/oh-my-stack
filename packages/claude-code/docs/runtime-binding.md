# claude-code runtime binding

Use the native Agent tool with the configured agent role/model. Preserve the workflow's specified worker count and order; distinguish requested model/effort from observed execution. Record unavailable cancellation or effort evidence explicitly.

Source-host helpers retained under a Skill's scripts directory are reference-only; their presence does not verify execution on this host.

Role contracts preserve upstream task semantics. Follow the selected workflow's stages and review standard. Delegate the workers that workflow calls for. Host authorization and available tool contracts continue to apply.
