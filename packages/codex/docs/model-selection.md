# Model selection

Collect a current inventory with scripts/collect-model-inventory.mjs --runtime codex. Review every model and effort before scripts/configure-models.mjs --apply. Preview is the default; --output writes only a detached destination. Native scope is ~/.codex and project .codex. scripts/model-resolution.mjs resolves nearest project first, then user configuration; each host owns an independent manifest. Fresh panels contain two entries. Same-target/same-preset reruns preserve saved membership, order, model and effort unless an explicit change requests otherwise. Missing observed model/effort selectors fail. Configuration artifacts do not prove native routing.

Saved personal configuration is the starting budget. Task selection does not rewrite it. Keep the configured model and family, panel membership, and order. Use only effort alternatives in the observed host inventory. Hardest work raises effort one supported level, capped at max or the highest advertised level below max. An explicitly saved effort above max remains unchanged. Judgment lowers it one level. Routine work lowers it two levels or to the lowest supported value. Verification keeps the configured model, effort, and speed. Other tasks request standard speed unless urgency calls for fast. Inherit-parent and auto aliases stay unchanged. Record the original role line, task choice, and any rejected adjustment. Requested settings do not prove backend enforcement.

Use scripts/codex-delegation.mjs prepare --job-context JOB.json --inventory INVENTORY.json. JOB.json contains kind hardest, judgment, routine, or verification and optional boolean urgent. Read audit.taskSelection for configured, selected, and requested values. Without a fresh inventory only the saved entry is available. After a confirmed host rejection of the adjusted choice, supply --rejected-adjustment REJECTION.json with the attempted model, reasoning, and host reason. The helper retries the original role line and records the rejection. The native spawn request has no speed selector, so the helper audits requested speed without emitting an invented field.
