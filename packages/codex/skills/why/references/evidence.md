# Evidence rules

Every rationale claim belongs to one tier:

| Tier | Required basis | Wording |
| --- | --- | --- |
| Direct | A source explicitly states the reason | State it with the exact citation. |
| Supported | Multiple independent indirect observations converge | Explain what each contributes and say the evidence supports it. |
| Inferred | A plausible interpretation with an explicit reasoning chain | Use appears, likely, or suggests; retain alternatives. |
| Speculative | Thin evidence with equally plausible alternatives | Label the hypothesis and missing evidence. |
| Unknown | Searches cannot answer the question | Name queries, gaps, and unavailable sources. |

Code behavior is not evidence of author intent. A comment may state intent but
is not proof of actual behavior. Metrics establish observations, not causality.
Copied accounts of one event are not independent corroboration. Absence from a
partial search is not evidence of absence.

Read source context, not only titles. Preserve conflicting statements, dates,
and citations. Distinguish original rationale from current justification. Never
upgrade confidence to match the user's hypothesis or make an explanation tidy.
Before delivery, verify citations and check that every causal phrase has the
claimed level of support. Redact secrets and unnecessary personal information.
